Privacy policy

Last updated: 2 October 2026

Ollie is a personal AI secretary. It is used only by its owner, who also runs it. It only responds to the owner's own WhatsApp number. This policy explains what data Ollie handles and how.

Data Ollie handles

  • WhatsApp messages the owner sends to Ollie, including voice notes.
  • Notes and reminders the owner asks Ollie to save.
  • Google Calendar events on the owner's own calendar. Ollie uses the calendar.events permission to list, create, update and delete events, and only when the owner asks.

Where it goes

  • Messages, notes, reminders and recent chat history are stored on the owner's private server.
  • To produce replies, message text and any calendar details needed for a request are sent to Google's Gemini API.
  • Voice notes are sent to Groq's speech-to-text API to be transcribed.
  • Calendar data is read from and written to Google Calendar through Google's API. It is not stored separately, apart from appearing in the chat history.

Sharing

Ollie does not sell, rent or share data with anyone. It is not used for advertising, and no data is used to train AI models by Ollie.

Google user data

Ollie's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Google Calendar data is used only to answer the owner's own requests.

Retention and deletion

Chat history is kept for the most recent messages only and can be cleared at any time with /reset. Calendar access can be removed at any time at myaccount.google.com/permissions.
